# GTF Tropilha Crioula

Site institucional do GTF Tropilha Crioula.

## Estrutura

Páginas: `index.html`, `o-tropilha.html`, `programas.html`, `curso-de-fandango.html`, `invernadas-artisticas.html`, `galeto-solidario.html`, `tropilanche.html`, `natal-solidario.html`, `eventos.html`, `transparencia.html`, `apoie.html`, `contato.html` e `404.html`.

- `styles.css`: identidade visual e layout responsivo.
- `img/`: fotos otimizadas (WebP). Logo, favicon e `og-image.png` na raiz.
- `robots.txt`, `sitemap.xml`: indexação.
- `render.yaml`: publicação e cabeçalhos HTTP no Render Static Site.

Site estático sem dependências e sem etapa de compilação. Abra `index.html` para visualizar localmente.

## Publicação no Render

Conectar este repositório ao Render, selecionar **Static Site**, usar a branch `main`, deixar o comando de build vazio e definir **Publish Directory** como `.`. Ativar publicação automática após alterações na branch `main`.

## Atualizações

Edite os arquivos e faça commit na branch `main`; a publicação no Render é automática. Se o domínio mudar, atualize as URLs em `index.html` (canonical e Open Graph), `robots.txt` e `sitemap.xml`.

## Conteúdo pendente

Adicionar história aprovada, logotipo oficial, fotografias autorizadas, agenda, endereço e canais de contato. Os textos iniciais são uma base editorial e devem ser revisados pelo grupo. Nenhum endereço, evento ou contato foi inventado.
